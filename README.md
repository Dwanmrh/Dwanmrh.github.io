# Portfolio - Muhammad Ridwan Hidayatullah

Static portfolio built with HTML and Tailwind CSS v4, hosted on GitHub Pages.

## Edit content
Edit `index.html`, then rebuild the CSS:

```
npm install
npm run build
```

`npm run dev` watches for changes while you edit.
The compiled file is `assets/css/style.css`. Commit it, because GitHub Pages serves it directly.
To update the CV, replace `assets/CV_Muhammad_Ridwan_Hidayatullah.pdf` with a file of the same name.

Project screenshots live in `assets/img/projects/` and certificate copies in `assets/img/certs/`, each in two
WebP sizes (a small one for the page, a large one for the enlarged view). `assets/Portfolio_Muhammad_Ridwan_Hidayatullah.pdf`
is the printable portfolio linked from the Projects and Contact sections.
